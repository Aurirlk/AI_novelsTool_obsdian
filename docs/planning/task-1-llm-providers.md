# LLM提供商调研报告

## 调研目标
调研当前主流的LLM提供商，特别是国内高性价比选项，评估其适用性。

## 国内高性价比LLM提供商

### 1. DeepSeek（深度求索）
- **模型**: DeepSeek V4 Pro, DeepSeek V4 Flash, DeepSeek R1
- **定价**: 
  - DeepSeek V4 Pro: 输入¥3/百万token，输出¥6/百万token
  - DeepSeek V4 Flash: 输入¥1/百万token，输出¥2/百万token
  - 缓存命中价格极低（¥0.02/百万token）
- **优势**: 
  - 性价比极高，输出价格仅$0.87/MTok
  - 支持1M上下文
  - 中国大陆直连，亚洲友好
  - 提供$5免费额度
- **劣势**: 
  - 速率限制较低（2 RPM）
  - 相对较新的提供商
- **适用场景**: 代码生成、长文档RAG、成本敏感应用

### 2. 阿里云（通义千问）
- **模型**: Qwen3 Max, Qwen3 Plus, Qwen3 Flash
- **定价**:
  - Qwen3 Max: 输入¥12/百万token，输出¥12/百万token
  - Qwen3 Plus: 输入¥2/百万token，输出¥8/百万token
  - Qwen3 Flash: 输入¥1.2/百万token，输出¥7.2/百万token
- **优势**:
  - 大厂稳定性，非英语表现最强
  - 支持262K上下文
  - 提供7000万token免费额度
  - 完善的生态系统
- **劣势**:
  - 旗舰模型价格相对较高
  - 分档定价可能增加复杂度
- **适用场景**: 多语言客户支持、企业级应用、需要稳定性的场景

### 3. 字节跳动（豆包）
- **模型**: Doubao Seed 2.0 Pro, Doubao Seed 2.0 Lite
- **定价**:
  - Doubao Seed 2.0 Pro: 输入¥3.2/百万token，输出¥16/百万token（0~32K）
  - Doubao Seed 2.0 Lite: 输入¥0.6/百万token，输出¥3.6/百万token（0~32K）
- **优势**:
  - 输入价格极低（¥0.6/百万token）
  - 提供50万token免费额度
  - 中国大陆直连
- **劣势**:
  - 上下文分档定价，长上下文成本跳档式上涨
  - 最大256K上下文
- **适用场景**: 成本敏感应用、短文本处理、快速原型

### 4. 智谱AI（GLM）
- **模型**: GLM-5, GLM-5.1, GLM-4.5-Air
- **定价**:
  - GLM-5: 输入¥7.2/百万token，输出¥23/百万token
  - GLM-5.1: 输入¥6/百万token，输出¥24/百万token
  - GLM-4.5-Air: 输入¥0.8/百万token，输出¥2/百万token
- **优势**:
  - 思维链质量最佳
  - 支持200K上下文
  - 提供免费额度
- **劣势**:
  - 旗舰模型价格较高
  - 相对较小的生态系统
- **适用场景**: 数学推理、形式推理、结构化分析

### 5. 月之暗面（Kimi）
- **模型**: Kimi K2.6, Kimi K2.5
- **定价**:
  - Kimi K2.6: 缓存命中保底价$0.07/MTok
  - 上下文分层输入定价（$0.16到$2.00/MTok）
- **优势**:
  - 最低缓存命中保底价
  - 超长上下文能力
  - 法律/金融/科研Agent专长
- **劣势**:
  - 定价结构复杂
  - 相对较新的提供商
- **适用场景**: 长系统提示词、法律/金融/科研应用

### 6. MiniMax（稀宇科技）
- **模型**: MiniMax M3, MiniMax M2.7
- **定价**:
  - MiniMax M3: 输入¥2.1/百万token，输出¥8.4/百万token
- **优势**:
  - 语言+视频+语音+图像+音乐五模态
  - 支持1M上下文
  - 性价比较高
- **劣势**:
  - 生态系统相对较小

## 选型建议

### 个人项目推荐组合
1. **主力模型**: DeepSeek V4 Pro（性价比最高，¥3/¥6）
2. **备用模型**: Qwen3 Plus（大厂稳定性，¥2/¥8）
3. **低成本模型**: Doubao Seed 2.0 Lite（¥0.6/¥3.6）
4. **推理模型**: DeepSeek R1（复杂推理任务）

### 成本估算（月度）
假设月度使用量：
- 输入: 1000万token
- 输出: 500万token

**DeepSeek V4 Pro成本**:
- 输入: 1000万 × ¥3/百万 = ¥30
- 输出: 500万 × ¥6/百万 = ¥30
- 总计: ¥60/月

**Qwen3 Plus成本**:
- 输入: 1000万 × ¥2/百万 = ¥20
- 输出: 500万 × ¥8/百万 = ¥40
- 总计: ¥60/月

**混合策略成本**（90% DeepSeek + 10% Claude）:
- DeepSeek部分: ¥54
- Claude部分: 约¥100
- 总计: ¥154/月

## 结论
国内LLM提供商在2026年已经非常成熟，性价比极高。DeepSeek在价格上具有绝对优势，阿里云在稳定性上领先，字节跳动在低成本场景表现突出。建议采用混合策略：简单任务用低成本模型，复杂推理用高能力模型，通过模型路由整体降低30-50%的API成本。
