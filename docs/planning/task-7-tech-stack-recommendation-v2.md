# 技术栈选择方案（更新版 - 低成本优化）

## 更新说明
根据用户反馈，LLM提供商成本过高，本版本采用更低成本的技术栈方案。

## 核心技术栈推荐

### 1. 工作流编排框架：LangGraph
**选择理由**:
- 可编程控制力最强，适合复杂多Agent系统
- 工程化程度高，生产级可观测性
- 社区活跃，LangChain生态支持
- 完全开源，无供应商锁定

### 2. LLM提供商：极低成本方案

#### 主力模型：智谱GLM-4-Flash（永久免费）
- **价格**: 完全免费，不限量
- **能力**: 相当于GPT-4o Mini水平
- **优势**: 永久免费、无token限制、中国大陆直连
- **适用场景**: 日常对话、写作、大纲生成

#### 备用模型：DeepSeek V4 Flash（极便宜）
- **价格**: 输入¥1/百万token，输出¥2/百万token
- **能力**: 更强的推理和代码能力
- **优势**: 性价比极高、支持1M上下文
- **适用场景**: 复杂推理、长文本处理

#### 本地模型：Ollama + Qwen3（完全免费）
- **价格**: 完全免费，无限制
- **能力**: 7B-70B模型可选
- **优势**: 数据隐私、离线可用、无延迟抖动
- **适用场景**: 隐私敏感、高频调用、离线环境

#### 成本对比
| 方案 | 月成本 | 适用场景 |
|------|--------|----------|
| 智谱GLM-4-Flash | ¥0 | 日常写作、大纲生成 |
| DeepSeek V4 Flash | ¥5-20 | 复杂推理、长文本 |
| Ollama本地 | ¥0（电费） | 隐私敏感、高频调用 |
| **混合策略** | **¥0-20/月** | **最优方案** |

### 3. 向量数据库：ChromaDB（免费）
**选择理由**:
- **完全免费**: 开源免费，无任何费用
- **开发友好**: Python原生，零配置
- **本地运行**: 无需额外部署
- **适合原型**: 快速验证，快速迭代

**与Qdrant对比**:
| 特性 | ChromaDB | Qdrant |
|------|----------|--------|
| 价格 | 免费 | 免费（自托管） |
| 部署 | 本地嵌入 | Docker部署 |
| 性能 | 中等 | 高 |
| 适用场景 | 原型/小规模 | 生产/大规模 |

**实施建议**:
- 原型阶段：使用ChromaDB快速验证
- 生产阶段：如果数据量>100万，考虑迁移到Qdrant

### 4. 结构化数据库：SQLite
**选择理由**:
- 零配置，文件数据库
- 完全免费
- 适合个人项目
- Python原生支持

### 5. 可观测性：LangSmith（免费层）
**选择理由**:
- 与LangGraph深度集成
- 免费层足够个人项目使用
- 监控、调试、评估功能完善
