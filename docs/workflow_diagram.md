## 智能体职责

### 1. 大纲师 (OutlineAgent)
```
输入: 用户创意
  │
  ▼
┌─────────────────────────────────┐
│ 1. 分析创意核心要素              │
│ 2. 设计世界观和力量体系          │
│ 3. 创建主要角色                  │
│ 4. 规划主线剧情                  │
│ 5. 设置核心悬念                  │
└─────────────────────────────────┘
  │
  ▼
输出: StoryBible
```

### 2. 码字工 (WriterAgent)
```
输入: 章节细纲 + 上下文
  │
  ▼
┌─────────────────────────────────┐
│ 1. 读取细纲和角色设定            │
│ 2. 检查最近章节内容              │
│ 3. 撰写2000字章节内容            │
│ 4. 保持人物性格一致              │
│ 5. 章末留悬念                    │
└─────────────────────────────────┘
  │
  ▼
输出: Chapter
```

### 3. 督察 (ReviewerAgent)
```
输入: 章节内容
  │
  ▼
┌─────────────────────────────────┐
│ 1. 时空一致性检查                │
│    - 角色位置是否合理            │
│    - 时间线是否连续              │
│                                 │
│ 2. 人物一致性检查                │
│    - 性格是否突变                │
│    - 行为是否符合设定            │
│                                 │
│ 3. 世界观一致性检查              │
│    - 是否违反设定规则            │
│                                 │
│ 4. 钩子检查                      │
│    - 是否有未回收的悬念          │
│                                 │
│ 5. 信息密度检查                  │
│    - 字数是否达标                │
│    - 内容是否有实质推进          │
└─────────────────────────────────┘
  │
  ▼
输出: ReviewResult (通过/不通过 + 问题列表)
```

### 4. 运营 (PolisherAgent)
```
输入: 审核通过的章节
  │
  ▼
┌─────────────────────────────────┐
│ 1. 优化章节标题                  │
│    - 吸引眼球                    │
│    - 有悬念感                    │
│                                 │
│ 2. 生成章末预告                  │
│    - 预示下章内容                │
│    - 吸引继续阅读                │
│                                 │
│ 3. 内容润色（可选）              │
│    - 增强画面感                  │
│    - 优化节奏                    │
└─────────────────────────────────┘
  │
  ▼
输出: 最终章节
```
